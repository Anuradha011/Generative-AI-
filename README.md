## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Anuradha011/Generative-AI-.git
```

### 2. Navigate to the Project Directory

```bash
cd Generative-AI-
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

On macOS or Linux:

```bash
source venv/bin/activate
```

### 4. Install Dependencies

If the project contains a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

Otherwise, install the dependencies required by the specific example you want to run.

### 5. Configure API Keys

If an example uses an external AI API, create a `.env` file in the appropriate project directory.

Example:

```env
OPENAI_API_KEY=your_openai_api_key
ANTHROPIC_API_KEY=your_anthropic_api_key
```

Install `python-dotenv` if required:

```bash
pip install python-dotenv
```

**Security reminder:** Never commit API keys, passwords, or other secrets to GitHub. Keep `.env` files out of version control.
